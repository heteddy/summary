# HMM vs CRF 对比总结

| 方面       | HMM                          | CRF                        |
| ---------- | ---------------------------- | -------------------------- |
| 类型       | 生成式模型                   | 判别式模型                 |
| 目标函数   | P(X,Y) 联合概率              | P(Y\|X) 条件概率            |
| 特征能力   | 有限，只能使用局部特征       | 强大，可以使用任意全局特征 |
| 独立性假设 | 观测独立假设                 | 无独立性假设               |
| 训练方法   | 有监督(最大似然)或无监督(EM) | 有监督(最大似然+正则)      |
| 计算复杂度 | 较低                         | 较高                       |
| 应用场景   | 简单序列标注任务             | 复杂特征依赖的任务         |
