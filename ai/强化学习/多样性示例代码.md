## Actor-Critic 重排模型实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
import numpy as np

# --- 1. 模型定义 ---

class ActorCritic(nn.Module):
    def __init__(self, state_dim, candidate_dim):
        super(ActorCritic, self).__init__()
        # --- Actor 部分：负责出动作 ---
        self.actor_layer = nn.Sequential(
            nn.Linear(state_dim, 128),      # 输入当前环境状态（如Query向量）
            nn.ReLU(),                      # 激活函数，增加非线性表达能力
            nn.Linear(128, candidate_dim)   # 输出层：维度等于候选文档总数
        )

        # --- Critic 部分：负责评估大局 ---
        self.critic_layer = nn.Sequential(
            nn.Linear(state_dim, 128),      # 同样输入当前环境状态
            nn.ReLU(),                      # 激活函数
            nn.Linear(128, 1)               # 输出层：只输出一个标量分数（V值）
        )

    def forward(self, state, mask):
        # 1. 计算 Actor 的原始输出（Logits，未归一化的得分）
        logits = self.actor_layer(state)

        # 2. 关键：遮掩（Masking）逻辑
        # 将 mask 向量中为 1 的位置（代表已选文档）在 logits 中填充为极负数
        # 这样在经过 Softmax 后，这些位置的概率会变成 0，防止重复选取
        logits = logits.masked_fill(mask == 1, -1e9)

        # 3. 将得分转化为概率分布（所有可选文档概率之和为 1）
        probs = F.softmax(logits, dim=-1)

        # 4. 计算 Critic 对当前状态的估分
        state_value = self.critic_layer(state)

        return probs, state_value # 返回概率分布（给Actor采样）和状态价值（给Critic参考）

# --- 2. 模拟环境与辅助函数 ---

    relevance = 0.8 

    # 计算多样性惩罚（余弦相似度）
    # 简化逻辑：这里仅演示计算思路

    redundancy = np.random.rand() * 0.5 # 模拟惩罚项

    return alpha * relevance - beta * redundancy
```

## 核心代码

1. **Mask 机制 (`logits.masked_fill`)**：
   
   在搜索场景中，一个文档不能被选两次。代码中通过 `mask` 强制将已选文档的概率降为 0。这是重排强化学习中**最重要**的工程处理。

2. **`advantage = returns - values.detach()`**：
   
   这是 Actor-Critic 的灵魂。
   
   - 如果 `advantage` 是正的，说明 Actor 这一步跳得比平均水平好，`log_probs` 前面的负号配合梯度下降，会**增加**该动作出现的概率。
   
   - `detach()` 是为了在更新 Actor 时，不要动 Critic 的权重。

3. **状态（State）的演变**：
   
   在我的代码里为了简化，`state` 是随机生成的。在你的真实业务中，第 1 步的 `state` 是 `[Query]`，第 2 步的 `state` 应该是 `[Query, 已选文档1]`，以此类推。

## 为什么这个代码能实现“多样性”？

因为你在 `get_reward` 函数里加入了**余弦相似度惩罚**。

- 当 Actor 连续选出两个非常相似的文档时，它会收到一个很低的 Reward。

- Critic 会感知到这种局势下的低分。

- Actor 经过多次“毒打”后，会发现：**“原来选一点不一样的文档，最终拿到的总分更高”**。

这就是强化学习自我进化的过程。
