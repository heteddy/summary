GMM（高斯混合模型）是一种基于概率分布的聚类算法，它假设数据由多个高斯分布混合生成，通过最大似然估计和EM算法求解。下面分别介绍其原理，以及与K-Means和DBSCAN的主要区别。

---

### 1. GMM聚类原理

- **模型假设**：数据点是从 \(K\) 个高斯分布（每个对应一个簇）的混合中生成的，每个分布有自己的均值 \($\mu_k$)、协方差矩阵 \($\Sigma_k$\) 和混合系数 \($\pi_k$\)（权重）。
- **求解目标**：估计所有参数，使得观测数据的似然函数最大。
- **EM算法**：通过迭代进行期望步（E步：计算每个点属于各高斯分布的后验概率）和最大化步（M步：更新参数）来求解。
- **簇分配**：每个点以不同概率属于所有簇（软分配），最终可选取概率最大的簇作为硬标签。

---

### 2. GMM vs. K-Means

| 维度        | GMM                      | K-Means         |
| --------- | ------------------------ | --------------- |
| **簇的形状**  | 可适应不同形状、大小、方向的簇（协方差矩阵可调） | 假设簇是球形且大小相似     |
| **分配方式**  | 软分配（概率值），给出不确定性度量        | 硬分配，每个点只属于最近的簇  |
| **理论基础**  | 基于概率模型，最大化似然             | 基于距离度量，最小化簇内平方和 |
| **对异常值**  | 受异常值影响（高斯假设），但可通过协方差约束缓解 | 异常值会显著影响簇中心     |
| **计算复杂度** | 较高，需迭代计算协方差矩阵的逆          | 较低，仅需计算均值       |
| **输出**    | 除了簇标签，还能提供每个点的后验概率       | 只有簇标签和簇中心       |

**核心区别**：K-Means是GMM的一种特例（当协方差矩阵固定为球形且各簇权重相等时），GMM更灵活，但需要更多参数和计算。

---

### 3. GMM vs. DBSCAN

| 维度        | GMM                | DBSCAN                                |
| --------- | ------------------ | ------------------------------------- |
| **簇的定义**  | 基于概率分布（高斯分布簇）      | 基于密度连通性（高密度区域）                        |
| **簇形状**   | 倾向于椭球形，不能发现任意形状    | 可以发现任意形状的簇（如环形、月牙形）                   |
| **簇数量**   | 必须预先指定 \(K\)       | 自动确定簇数，无需预设                           |
| **噪声处理**  | 通常将每个点分配到某个簇，不识别噪声 | 能识别并标记噪声点（不属于任何簇）                     |
| **参数依赖**  | 需要指定 \(K\) 和协方差类型  | 需要指定邻域半径 \(\varepsilon\) 和最小点数 MinPts |
| **对密度不均** | 可处理不同密度（通过协方差矩阵）   | 对密度变化敏感，全局参数难以适应                      |
| **适用场景**  | 数据大致服从混合高斯分布，需要软聚类 | 数据有复杂形状，包含噪声，簇数量未知                    |

**核心区别**：DBSCAN是密度聚类，不需要预设簇数，能发现任意形状并识别噪声；GMM是模型聚类，要求数据符合高斯假设，簇数为先验。

---

### 4. 总结

- **GMM** 适合数据呈现椭球形分布、需要软聚类（概率输出）的场景。
- **K-Means** 适合簇大小均匀、球形且对速度要求高的场景。
- **DBSCAN** 适合簇形状复杂、包含噪声、簇数量未知的场景。

选择算法时需根据数据特点和应用需求权衡。
