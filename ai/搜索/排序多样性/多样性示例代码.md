多样性强化学习

## Actor-Critic 重排模型实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
import numpy as np

# --- 1. 模型定义 ---

class ActorCritic(nn.Module):
    def __init__(self, state_dim, candidate_dim):
        super(ActorCritic, self).__init__()
        # --- Actor 部分：负责出动作 ---
        self.actor_layer = nn.Sequential(
            nn.Linear(state_dim, 128),      # 输入当前环境状态（如Query向量）
            nn.ReLU(),                      # 激活函数，增加非线性表达能力
            nn.Linear(128, candidate_dim)   # 输出层：维度等于候选文档总数
        )
        
        # --- Critic 部分：负责评估大局 ---
        self.critic_layer = nn.Sequential(
            nn.Linear(state_dim, 128),      # 同样输入当前环境状态
            nn.ReLU(),                      # 激活函数
            nn.Linear(128, 1)               # 输出层：只输出一个标量分数（V值）
        )

    def forward(self, state, mask):
        # 1. 计算 Actor 的原始输出（Logits，未归一化的得分）
        logits = self.actor_layer(state)
        # 2. 关键：遮掩（Masking）逻辑
        # 将 mask 向量中为 1 的位置（代表已选文档）在 logits 中填充为极负数
        # 这样在经过 Softmax 后，这些位置的概率会变成 0，防止重复选取
        logits = logits.masked_fill(mask == 1, -1e9)
        
        # 3. 将得分转化为概率分布（所有可选文档概率之和为 1）
        probs = F.softmax(logits, dim=-1)
        
        # 4. 计算 Critic 对当前状态的估分
        state_value = self.critic_layer(state)
        
        return probs, state_value # 返回概率分布（给Actor采样）和状态价值（给Critic参考）
# --- 2. 模拟环境与辅助函数 ---

def get_reward(selected_idx, candidates_vec, alpha=1.0, beta=0.5):
    """    计算奖励：相关性 - beta * 最大余弦相似度    """
    # 模拟相关性分数（实际中由第一阶段DL提供）
    relevance = 0.8 

    # 计算多样性惩罚（余弦相似度）
    # 简化逻辑：这里仅演示计算思路
    # redundancy = max_cosine_similarity(selected_doc, already_selected_docs)
    redundancy = np.random.rand() * 0.5 # 模拟惩罚项

    return alpha * relevance - beta * redundancy

# --- 3. 训练主循环 ---

# 初始化超参数
STATE_DIM = 1024      # 假设状态向量维度
CANDIDATE_COUNT = 10 # 候选池大小
TOP_K = 3           # 需要选出的文档数

# 状态向量 是query_embedding + doc_embedding

model = ActorCritic(STATE_DIM, CANDIDATE_COUNT)
optimizer = optim.Adam(model.parameters(), lr=0.001)

def train_one_episode():
    # 初始化一个搜索请求的状态（模拟 Query 向量）
    state = torch.randn(1, STATE_DIM)
    # 初始化遮掩向量，开始时所有文档都是可选的（全0）
    mask = torch.zeros(CANDIDATE_COUNT) 
    
    log_probs = [] # 用于存储 Actor 选择动作时的对数概率
    values = []    # 用于存储 Critic 每一轮给出的预估分
    rewards = []   # 用于存储 环境（搜索结果）给出的真实奖励

    # --- 阶段一：执行动作（生成排序列表） ---
    for _ in range(TOP_K): # 比如我们要选出 Top-3
        # 运行模型，获取当前的概率分布和 Critic 的预估分
        probs, value = model(state, mask)
        
        # 创建一个概率分布对象
        m = torch.distributions.Categorical(probs)
        # 按照概率进行“随机采样”，选出一个文档索引（增加探索，避免总是选同一个）
        action = m.sample()
        
        # 记录下这一步的 log 概率，后面算梯度要用到
        log_probs.append(m.log_prob(action))
        # 记录下这一步 Critic 认为能拿多少分
        values.append(value)
        
        # 将选中的文档在 mask 中标记为 1，下次循环就不选它了
        mask[action] = 1
        # 计算真实奖励：这里的逻辑是你之前定义的（相关性 - 余弦相似度惩罚）
        reward = get_reward(action, None) 
        rewards.append(reward)
        
        # 更新状态：真实场景中，你会把已选文档的信息融合进新的 state 里
        state = torch.randn(1, STATE_DIM) 

    # --- 阶段二：计算损失并学习 ---
    returns = [] # 存储每个步骤对应的“未来累积总奖金”
    gt = 0
    # 强化学习公式：从后往前算，越远的奖励折扣越大
    for r in reversed(rewards):
        gt = r + 0.9 * gt # 0.9 是折扣因子，代表我们更看重眼前的奖励
        returns.insert(0, gt)
    
    returns = torch.tensor(returns) # 转换为张量
    values = torch.cat(values).squeeze() # 将列表转换为一维张量
    log_probs = torch.cat(log_probs)    # 同样转换 log 概率

    # 计算优势（Advantage）：真实拿到的奖金 - Critic 预期的奖金
    # 如果结果 > 0，说明 Actor 表现超常；如果 < 0，说明选烂了
    advantage = returns - values.detach()

    # Actor 损失函数：
    # 我们希望概率大的动作，带来的 advantage 也是正的
    # 加负号是因为 PyTorch 做的是梯度下降（我们要最大化奖励，即最小化负奖励）
    actor_loss = -(log_probs * advantage).mean()
    
    # Critic 损失函数：
    # Critic 应该努力让自己的预估值（values）接近真实值（returns）
    critic_loss = F.mse_loss(values, returns)

    # 总损失 = 策略损失 + 价值损失（0.5是权重系数）
    loss = actor_loss + 0.5 * critic_loss
    
    # 清空旧梯度
    optimizer.zero_grad()
    # 计算新梯度
    loss.backward()
    # 更新神经网络参数
    optimizer.step()

    return sum(rewards) # 返回这一局的总分，方便我们观察模型有没有进步

# 模拟训练 100 次
for i in range(100):
    total_r = train_one_episode()
    if i % 10 == 0:
        print(f"Episode {i}, Total Reward: {total_r:.4f}")
```

## 核心代码

1. **Mask 机制 (`logits.masked_fill`)**：
   
   在搜索场景中，一个文档不能被选两次。代码中通过 `mask` 强制将已选文档的概率降为 0。这是重排强化学习中**最重要**的工程处理。

2. **`advantage = returns - values.detach()`**：
   
   这是 Actor-Critic 的灵魂。
   
   - 如果 `advantage` 是正的，说明 Actor 这一步跳得比平均水平好，`log_probs` 前面的负号配合梯度下降，会**增加**该动作出现的概率。
   
   - `detach()` 是为了在更新 Actor 时，不要动 Critic 的权重。

3. **状态（State）的演变**：
   
   在我的代码里为了简化，`state` 是随机生成的。在你的真实业务中，第 1 步的 `state` 是 `[Query]`，第 2 步的 `state` 应该是 `[Query, 已选文档1]`，以此类推。

---

## 为什么这个代码能实现“多样性”？

因为你在 `get_reward` 函数里加入了**余弦相似度惩罚**。

- 当 Actor 连续选出两个非常相似的文档时，它会收到一个很低的 Reward。

- Critic 会感知到这种局势下的低分。

- Actor 经过多次“毒打”后，会发现：**“原来选一点不一样的文档，最终拿到的总分更高”**。

这就是强化学习自我进化的过程。
